The Story

Everything below is built from the entries in the curated prompt log, grouped into the rough eras the work actually fell into. Entry numbers, dates, and commit hashes are cited so every claim traces back to something checkable — see the log itself, or the raw transcripts underneath it, for the receipts.

1. Setting the guardrails

Entries 1–2, 14 · 2026-05-21 · branches dev, claude/frosty-hoover-765d4c

Before any code existed, the first session (entry 1) was a security conversation: restrict the agent to the D:\Git_NAE directory, nothing else, and don't change anything yet — just look. The second session that same day (entry 2) stood up the actual git workflow: commits 4c52d9e (CI + branching docs) and 158d285 (a .gitignore covering Windows, editors, Claude Code, and secrets). This is where the main / prototype / feature/* flow that still governs the repo was first written down.

A third same-day session (entry 14) added the GitHub-side enforcement: branch protection on prototype, required status checks, pull requests required before merging. No commit trail survives for that branch specifically — it was UI configuration, not code — but the ruleset it set is the one still active. Three sessions, one day, and the fence was up before the first prototype existed.

2. First prototype through V2

Entries 3–7 · 2026-05-21 → 05-26 · branches claude/frosty-driscoll-15130d, claude/determined-williams-8ac428, claude/blissful-franklin-a7b245 → claude/vigilant-lovelace-2cb582

Entry 3 is a single "stop planning, start building" prompt that produced 237f7b7, the seed of what would be tagged v1. Entry 4 built the actual scent-mapper over 19 prompts — and a lot of the product's lasting DNA got set here: blackcurrant got rejected as a reference flavor because most people have never tasted it, a checkbox legend replaced an opaque toggle, and the self-reported "smeller profile" idea was killed as unhelpful. It shipped as PRs #1 and #2, tag v1. Entry 5 was a deliberately no-code session — checking α-terpineol, black-tea, and elderflower compounds against the literature before adding them — setting a pattern of vetting sources before they entered the data that the project never dropped.

Entry 6 is the biggest single session in the log: 86 prompts, two stories braided together. First, a security fix — API and SSH keys spotted in a repo about to go public, pulled out, with the rule that secrets live outside the repo on the D drive. Second, the full V2 redesign, shipped in slices: the ortho/retro input contract (a1053bf), three view modes replacing an earlier sensory/compounds split (1a3a173), the "i" info tab (aa88323), a Methodology tab with citations, the Note Suggester modal (e4b03b1, 38abf30, 11ff598), a copy pass (fc4b3cd), and a compound-library expansion (e315ce2). It merged at 20643d3, tagged v2, via PR #4. This is also where the project's voice got decided — more on that in Section 2. Entry 7, a one-line confirmation that prototype/index.html was canonical, closes out the chapter.

3. Scoping the audience and the stance

Entries 8–13 · 2026-05-23 → 06-12 · branches main, prototype, claude/header-cleanup → feature/compound-lens, feature/prompt-log

Entry 8 is a no-code design session that re-litigated the core stance and landed a durable rule: real compound names should always be present somewhere, even at low confidence, whether or not the wheel splits notes from taste-alikes. Entry 9 audited the scent library for gaps a quick search would surface (rose, oak-barrel compounds), and is where a guardrail that gets repeated throughout the log first shows up on the record: the tone was drifting too wine-specific and got pulled back.

Entry 10 caught main up to prototype via PR #5 (74bd1ef) and built the ortho/retro 101 explainer, with heavy copy correction along the way. Entry 11 fixed a stubborn wheel-label collision problem through several rounds of pixel-level tuning (79ebf6b, c1758c0, e07e6ab, c99e00d) — the kind of iteration invisible in the finished product but that was most of the actual work. Entry 12 shipped compound common-names on hover (aa326b7) after a real "why does 1,8-Cineole also say eucalyptol?" moment of confusion on the live site, and renamed the Results pane to Compounds. Entry 13 is the session that built the first version of this very log — auto-extracting 192 prompts from local transcripts into a curated record.

4. The UX grade, citations, and the Compass

Entries 15–18 · 2026-06-09 → 06-26 · branches claude/thirsty-dijkstra-de159b, claude/compound-library/claude/citation-audit, claude/upbeat-mendel-6ef2f6

Entry 15 opened by grading the app itself — usability, discoverability, audience — before touching any code, then worked the resulting list start to finish: a first-run nudge, a 760px mobile breakpoint, a saturated data palette, label-clipping fixes, and an em-dash/AI-isms copy strip. It shipped as PR #8. Entry 16 pushed hard on citation legitimacy ("are there not citations we can get from within the last decade?"), landing PR #11's fix of eight unverifiable citations plus new SOURCES and SCOPE docs, and added dedicated strawberry/blueberry/blackberry notes after noticing the Note Suggester was flattening real flavor differences into one generic "berry."

Entry 17 turned a live Netlify-preview review into a full onboarding pass: a tagline, explicit scope statement, seven example demos, and INFERENCE.md. It also walked back an over-literal "cotton candy" input in favor of staying compound-forward with a parenthetical common-name gloss — a good early example of the compound-forward stance actually getting enforced against itself. Entry 18, 30 prompts over two days, recovered a compound-library expansion that had gone missing in a stray commit, decoupled full citations from the Go Deeper toggle, built device-motion Jiggle, a five-ring "event horizon" transition, and — from the user sharing screenshots of an earlier personal prototype — the Perception Compass, merged via PR #14.

5. Varietals, taxonomy, and the birth of Tree

Entries 19–22 · 2026-06-27 → 07-01 · branch claude/mobile-ui-pass-3

Entry 19 opened by modeling the app at Galaxy S10e portrait dimensions "because that's honestly how it will be demoed irl," then built the first Go Deeper varietal-distinction table for citrus, extended to berry and mint — each backed by a real distinguishing compound where the literature actually supported one. Entry 20 is where the Tree workspace itself was born, from a direct request to put every flavor note on a taxonomy tree as a third viewer alongside Wheel and Map (fcdd956). The same session also made varietal children independently scoreable rather than locked to their parent's slider, and fixed a precise bug report about Cranberry's compounds not lighting up correctly when scored alone.

Entry 21 was one long, open-ended UI brief ("Opus you have such taste above chatgpt, own it") that produced a saturation-as-evidence palette, a reading/dyslexia mode, and a "you might also smell" bouquet readout — then a self-correction when mobile hadn't gotten the same attention as desktop. Entry 22 spent seven prompts purely on the wheel's float physics, working from the user's own gas-molecules-in-a-balloon metaphor through an overcorrection into "rave mode" and back to a calmer settled state.

6. Mobile ideas, the honesty policy, and an identity

Entries 23–26 · 2026-07-01 → 07-04 · branch claude/mobile-ui-pass-3 → feature/favicon-polish

Entries 23 and 24 opened within the same minute with near-identical prompts — one a deliberately code-free ideas workbench, the other where the actual work landed: touch-reachable explanatory text for users without hover, and the citation honesty policy that still governs UNVERIFIED_REFS today. Entry 25 pushed the Tree further — a real physics rework with cached "home" positions, a polar layout where angle encodes which notes feed a compound and radius encodes evidence strength, vertical rotation, and family detail pages — closing with PR #15 merging 48 commits into prototype.

Entry 26, 34 prompts, is a genuine identity/branding session: whether to put a legal name on a public repo, working through a privacy tension that ended on "Nolan [Æ]" and the brand name iconic-orion, distinct from the generic "aroma wheel" term since someone already holds a claim on "wine aroma wheel." It also fixed a real mobile bug — dismissible helper boxes that were impossible to close on a phone.

7. feature/bloom, and letting ChatGPT into the room

Entries 27–34 · 2026-07-04 → 07-11 · branches feature/bloom, codex/aroma-wheel-responsive-ux-pass

Entry 27 stated the thesis for feature/bloom directly: quick-use should be just as powerful as Go Deeper, and Go Deeper should "bloom" into extended science rather than gate basic use. That thesis produced the naturalist canopy-to-soil reframing of Go Deeper's transition (0102cb4, 6d4689a) and a client-side, backend-free shareable tasting-card export. Entry 28 built the map inset for that card's flip layout and made Reading Mode the default state, collapsing a growing settings surface back down on the explicit principle that "too many options" was itself the problem.

Entry 29 is where the codex/* containment policy now in CLAUDE.md was set: one branch namespace ChatGPT may touch, motivated by keeping any new model's bugs contained rather than by distrust of its work quality. Entry 30 was the first post-hoc review of ChatGPT's actual output there, formalizing the working agreement. Entries 32–34 scoped and ran a tightly bounded review of the shareable-card UI specifically, correcting the card's "More stunning" style to drop everything but flavor notes and dominant compounds, and extended Claude's own commit access to the codex branch as a standing rule rather than a one-off. In between, entry 31 closed the meats/eggs/stocks idea that had been queued since entry 20 — "i dont want to explore meats anymore. i think i want to keep this mostly botanical focused" — and marked feature/bloom itself as a historical baseline predating the dual-agent era.

8. Systems thinking: laps, strata, and the GIS turn

Entries 35–38 · 2026-07-25 → 07-26 · branch codex/aroma-wheel-responsive-ux-pass

Entry 35, 33 prompts, opened as an orientation check on a branch that had drifted, then made a real design correction: Map was demoted from a peer pane in a three-way switcher to its own dedicated button, because a flat tab switch understated the link between the family tree and the chemical analysis. It documented the mobile-first product-design contract (17c7fdd), shipped Laps — timestamped tasting snapshots stacking like geological strata — and Delivery as a third sensory dimension, and kicked off the prompt-log integrity effort that produced entries 14–37 of this very log, from a direct ask for a "defensible 'here is the human work.'"

Entries 36 and 37 are parallel continuation sessions working from a written handoff doc, both largely in an explicit watch-not-touch mode while ChatGPT live-edited the map's data layers. Entry 37 diverges at the end with a concrete design idea relayed from a conversation with ChatGPT: the Tree "might do better if when you zoom to family level it looks more like a wreath." Entry 38, a short same-evening tail, greenlit reading the Tree's family scale as leaves rather than branches — landing as 060519e and 1a557ee.

9. Trusting codex, the conical helix, and Constellation

Entries 39–41 · 2026-07-27 → 08-01 · branch codex/aroma-wheel-responsive-ux-pass

Entry 39 is short but structurally important: a direct correction of Claude's own caution, overriding the pre-existing extraction/re-implementation gate on codex/* merges after hands-on testing of ChatGPT's newest model. That's the origin of the policy update now recorded in CLAUDE.md. Entry 40 treated codex's prior mobile-visualization work as a running start, landed a purely visual pass on the Tree (bd00f53), then, after a correction that desktop was still cramped, the conical-helix layout itself (61d069f).

Entry 41 is where Constellation — Go Deeper's subjective "maker's mind" hemisphere — got built, largely in the user's own words describing three lenses: chemistry, taxonomy, and world-map geography, as a separate space from the wheel's practical, citation-based mode. It shipped as 482729a, was promoted to a direct header toggle after a "wait, where is it?" correction (d8dc2a3), and had a real functional bug — not updating with active tasting notes — fixed the same session (f980b88).

10. The merge checkup, the honest voice, and the relationships

Entries 42–45 · 2026-08-04 → 08-15 · branches codex/aroma-wheel-responsive-ux-pass → codex/tasting-relationship-guidance

Entry 42, 24 prompts, was a pre-merge usability and language checkup keyed toward the audience Go Deeper is actually for, and included a real structural pivot mid-session: the working branch itself was renamed to reflect a shift toward surfacing relationships between notes rather than just responsive polish. It ungated Map and Tree from behind Go Deeper, built one shared relationship engine behind Wheel and Constellation, and — from a question about whether banana's aroma compounds reflect modern cultivars or older varieties that no longer exist — added a "widely-repeated claims" evidence tier distinct from verified sourcing.

Entry 43 walked back the citation honesty policy's own copy as counterproductive (more on this in Section 2) and ran a voice pass: no idioms unless the user's own, minimal em dashes, no semicolons, no contractions outside quoted literature. Entry 44 shipped a proportional Venn diagram for compound overlap between notes, born from the user noticing "Strongest: Lychee" under a rose tasting and wanting a shape to reason with rather than a bare percentage — plus a run of mobile fixes and the always-accessible Enter tasting button, closing with the PR to prototype that became PR #20. Entry 45, a single one-line prompt, promoted that work from prototype to main as PR #21 — the second time this exact request has been made, after entry 39's PR #19.

How ideas evolved

The chapters above show the shape of the project. This section does something narrower: it picks specific ideas that visibly changed over time and traces each one through the actual words that changed it, in order. Every quote below is pulled directly from the prompt log — either from the curated README's own quoted fragments, or, where noted, verified against the verbatim raw transcripts. Dates and entry numbers sit next to each one so the chain can be checked.

"Your perceptions are real, and they change"

The project's core stance, stated once, then tested, then lived out.

Entry 6 · 2026-05-23 → 05-26
"Yes the tone of the entire project is. Your perceptions are real, and they are going to change depending on what exact moment you use the tool. It's gustatory agnostic…"
The stance is stated flatly, as a direct answer to a question about tone — and immediately scoped: gustatory-agnostic in principle, but edible-only in practice for now.
Entry 8 · 2026-05-23
"Let's really think about if this is the right stance? : ('here's the chemistry your perception implies')…"
Days later, the same idea gets re-litigated rather than assumed — the stance survives its own stress test, reframed as "here's the chemistry your perception implies" instead of a claim about ground truth.
Entry 44 · 2026-08-14
"that's kind of neat if I start saying I smell 'lychee' when I'm smelling rose"
Three months later, the abstract stance shows up as a lived reaction to the tool's own output — scoring a rose tasting and finding "Strongest: Lychee," and treating that as an invitation rather than a correction.

The citation honesty rule

Pushed for, then built as an explicit policy, then rewritten because the policy's own wording undermined it.

Entry 15 · 2026-06-09 → 06-11
"are there not citations we can get from within the last decade?"
The earliest push is simple: are these sources actually current. That question is what starts the project interrogating its own citations rather than just adding them.
Entry 24 · 2026-07-01
"i think i also need an honesty policy in here where all citations have a 'under human review' until I personally review them"
That becomes an explicit rule (50996dd): unverified sources render as under review rather than getting silently trusted. This is still the mechanism behind UNVERIFIED_REFS today.
Entry 43 · 2026-08-04 → 08-05
"it makes it sound dishonest and possibly completely false… just say what criteria was considered for choosing works cited to rely on"
A month later, the underlying practice doesn't change — but the copy describing it does (850afa1). The honesty policy had started reading as an admission of doubt instead of a description of a process, and got rewritten to state the actual selection criteria instead.

The mobile-first pivot

From "test it at phone size" to a documented product-design contract.

Entry 19 · 2026-06-27 → 06-28
"…because that's honestly how it will be demoed irl"
The Galaxy S10e portrait viewport becomes the working reference size for a very practical reason — that's the actual demo conditions — not an abstract accessibility ideal.
Entry 21 · 2026-06-29 → 07-01
"argh, mobile ui didn't get the same attention"
A long open-ended desktop UI brief gets self-corrected mid-session once the gap becomes visible — mobile gets its own matching treatment (natural page scroll, a fixed Tasting Tray) in the same session rather than a later pass.
Entry 35 · 2026-07-25 → 07-26
"i know overall i was working on ui design for both desktop and mobile versions and trying to figure out how to clean up the overall transitions between different features… so that it is more seamless when someone is in the middle of a tasting session…"
What had been recurring in-session corrections finally gets written down as a standing rule: the mobile-first product-design contract now in CLAUDE.md (17c7fdd) — named viewport classes, no critical control may clip, pane ownership belongs to the user.

The Tree's taxonomy: tags to a real tree to a spiral to leaves

The longest-running visual-design thread in the project.

Entry 20 · 2026-06-28 → 06-29
"can we put all of the flavor notes on a taxonomy tree? this is the third viewer along with wheel and map"
A Phase 1 family-tag layer (added earlier the same session) becomes a full Kingdom→Order→Family→Note dendrogram — a real phylogenetic depth, not just a label on a note.
Entry 37 · 2026-07-26
"might do better if when you zoom to family level it looks more like a wreath… to carry over the circle design of aroma wheel"
A design idea relayed from a conversation with ChatGPT reframes the family level visually, tying the Tree's shape back to the Wheel's.
Entry 40 · 2026-07-30
"desktop view is still pretty unviewable because its a super side but short interactive… is there another way to show hierarchy while spiraling?"
A purely visual pass turns out not to use the desktop screen well; naming that problem directly produces the conical-helix layout (61d069f).
Entry 38 · 2026-07-26
"yeah maybe it should read as leaves at that point yes you go for it with your ui artistry"
The family scale gets read as leaves rather than branches (060519e), then as growth rings (1a557ee) — the wreath idea from entry 37 finding its literal shape.

ChatGPT and the codex branch: quarantine to trust

From containment to an explicit reversal of Claude's own caution.

Entry 29 · 2026-07-11
"in case any new openai models hopefully will keep whatever bugs or snips inside its own area and we keep most of the repo supported solely by claudel"
The codex/* policy starts as containment, stated plainly as such — not a judgment about ChatGPT's work quality, a fence around risk.
Entry 34 · 2026-07-11
"update the rule where you can also update this branch. this is just the only one i want chatgpt touching"
Claude's access to the codex branch, previously a one-off exception, becomes a standing rule — the fence stays, but it stops being one-directional.
Entry 39 · 2026-07-27
"that's against the branching rule in CLAUDE.md… I trust codex to do everything claude can do now that Ive had time to test their newest model. its trustworthy."
The extraction/re-implementation gate — a rule Claude had cited back defensively — gets explicitly overridden. codex/* can merge directly into prototype; Claude's review moves from a pre-merge gate to periodic post-hoc review, as it still is today.

Go Deeper's ortho/retro mechanism

From a data-logging toggle to a framing for a whole audience.

Entry 6 · 2026-05-23 → 05-26
"So yes being able to click either ortho (sniff) or retro (swallow) and that option should always be available for the user to flag for themselves. and that can be another visibility toggle in the legend."
Ortho/retro starts as an always-visible flag on every note, sitting in the legend alongside other visibility toggles.
Entry 6 · 2026-05-23 → 05-26
"ortho nasal is fine behind an advanced frame"
Within the same session, the mechanism gets pulled back behind an advanced frame — the first move toward what becomes Go Deeper.
Entry 6 · 2026-05-23 → 05-26
"every taste note on the left pane can have ortho/retro on there and that is what confirms the note's presence on the central wheel and in the analysis. to confirm you need to select ortho(sniff) or retro(Swallow)."
It generalizes further — from an optional flag to the actual confirmation mechanism for entering a note at all, with a checkmark indicator so a user knows what they've already logged.
Entry 42 · 2026-08-06 → 08-07
"im really trying to key into the people that will use go deeper because they are inquisitive and want to go deeper into how these notes relate and how to detect these different compounds by inferring from detecting flavors/aromas with our senses."
Months later, Go Deeper stops being framed as a data-input mechanism at all and gets explicitly redefined around an audience — people curious about relationships between notes, not just a stricter logging mode. Map and Tree get ungated from behind it the same session.

Two threads worth naming were considered and dropped. The "no invented distinguishing compound" pattern (noStandoutNote) is real and consistently applied — but the log only carries one clean verbatim quote for it (entry 19's berry table framing), not enough steps to call an evolution rather than a single decision. The economic-cultivation and cultural-value map layers mentioned in CLAUDE.md are explicitly still unstarted, pending design approval, so there's no mutation to trace yet.
